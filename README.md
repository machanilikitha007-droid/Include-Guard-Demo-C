# Include Guard Demonstration in C

## Project Description

This project demonstrates the use of include guards in C header files. Include guards prevent multiple inclusions of the same header file during compilation.

The program uses `#ifndef`, `#define`, and `#endif` directives to ensure that the contents of `student.h` are included only once.

## Features

- Demonstrates include guards
- Uses custom header files
- Prevents multiple inclusion errors
- Shows use of preprocessor directives

## Technologies Used

- C
- Preprocessor Directives
- Header Files

## Files

- `main.c`
- `student.h`
